# Data

Inputs for the AnimateCar3D demos and tests: scene lists, motion files, and static scenes.

- `frameRate_results.csv`: the timing results written by `script_AnimateCar3D_frameRateTest.m` (see "Frame rate" in the main README)

Vehicle meshes are not kept here: they come from the CarMesh3D library's `Data` folder (see the main README for which copy of CarMesh3D is used).
